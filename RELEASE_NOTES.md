# Research artifacts

Includes experiment code, launchers, analysis plans and aggregate results for the paper.
Includes CPU checks, table renderers, plot scripts, model metadata and dataset acquisition instructions.
Includes reproducible synthetic BA records and hashes.
Numeric manuscript claims are recorded in paper_numbers/MANUSCRIPT_TRACE.csv.
The confirmed manuscript pins and unresolved claims are disclosed in paper_numbers/coverage.json.
Human-validation results from both completed author ratings are included.
Real PII, corpus text, AIA text, raw generations, rater sheets, private keys, weights and adapters are withheld.
The CPU checks verify released aggregates; GPU experiments require separately acquired data and models.
